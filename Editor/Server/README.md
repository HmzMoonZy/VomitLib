# VomitLib 服务器管理工具

这个工具集成到Unity编辑器中，提供了便捷的服务器管理功能，包括启动、停止、监控服务器状态和查看实时输出。

## 功能特性

### 🚀 核心功能
- **一键启动/停止服务器** - 直接在Unity工具栏中操作
- **实时状态监控** - 工具栏按钮颜色显示服务器运行状态
- **实时输出查看** - 专用窗口显示服务器日志
- **自动构建** - 启动前自动构建服务器项目
- **快捷键支持** - 提供便捷的键盘快捷键

### 📊 服务器输出窗口功能
- **实时日志显示** - 服务器和构建输出实时更新
- **智能过滤** - 支持关键词过滤日志内容
- **颜色分类** - 错误、警告、普通信息不同颜色显示
- **时间戳** - 可选显示每条日志的时间戳
- **自动滚动** - 新日志自动滚动到底部
- **日志保存** - 支持将日志保存为文本文件
- **行数限制** - 可配置最大日志行数避免内存问题

## 使用方法

### 1. 配置设置

首先需要在VomitConfig中配置服务器路径：

1. 在Unity编辑器工具栏点击"配置文件"按钮
2. 在Inspector中找到"Net 配置"部分
3. 设置以下参数：
   - **Server Path**: 服务器项目相对于Unity项目根目录的路径（默认: `Server/`）
   - **Game Server Ip**: 服务器IP地址（默认: `127.0.0.1`）
   - **Game Server Port**: 服务器端口（默认: `20001`）

### 2. 工具栏按钮

在Unity编辑器顶部工具栏中，你会看到两个新按钮：

#### 启动/停止服务器按钮
- **绿色** = 服务器正在运行，点击停止
- **红色** = 服务器已停止，点击启动
- 启动时会自动构建服务器项目

#### 服务器输出按钮
- 打开服务器输出窗口
- 查看实时日志和构建信息

### 3. 菜单选项

通过 `VomitLib/Server/` 菜单访问所有服务器管理功能：

- **启动服务器** (Ctrl+Shift+S) - 构建并启动服务器
- **停止服务器** (Ctrl+Shift+X) - 停止正在运行的服务器
- **重启服务器** (Ctrl+Shift+R) - 停止并重新启动服务器
- **构建服务器** - 仅构建服务器项目，不启动
- **服务器输出窗口** - 打开日志查看窗口
- **打开服务器文件夹** - 在文件管理器中打开服务器目录

### 4. 服务器输出窗口

点击"服务器输出"按钮或菜单选项打开输出窗口：

#### 工具栏功能
- **状态指示器**: 显示服务器当前运行状态（绿色=运行中，红色=已停止）
- **过滤框**: 输入关键词过滤日志内容
- **时间戳**: 开启/关闭时间戳显示
- **自动滚动**: 开启/关闭自动滚动到最新日志
- **自动换行**: 开启/关闭长文本自动换行
- **清空**: 清除所有日志内容
- **保存**: 将当前日志保存为文本文件
- **最大行数**: 设置日志缓存的最大行数（100-10000）

#### 日志颜色编码
- **红色**: 错误信息（Server Error, Build Error）
- **黄色**: 警告信息（Warning）
- **白色**: 普通信息
- **青色**: 状态变更信息

## 技术实现

### 架构设计
- **ServerManagerTool**: 核心服务器管理逻辑
- **ServerOutputWindow**: 日志显示窗口
- **ToolBarMenu**: 工具栏集成
- **NetConfig**: 服务器配置管理

### 进程管理
- 使用 `System.Diagnostics.Process` 管理服务器进程
- 重定向标准输出和错误流捕获日志
- 支持异步操作避免阻塞Unity编辑器
- 自动清理资源防止进程泄露

### 事件系统
- `OnServerStatusChanged`: 服务器状态变更事件
- `OnServerOutput`: 服务器输出事件
- 编辑器生命周期集成，退出时自动停止服务器

## 故障排除

### 常见问题

1. **"未配置服务器路径"错误**
   - 检查VomitConfig中的ServerPath设置
   - 确保路径相对于Unity项目根目录正确

2. **"未找到服务器文件"错误**
   - 确保服务器项目已正确放置在指定路径
   - 检查Geek.Server.sln文件是否存在

3. **构建失败**
   - 确保已安装.NET 7.0 SDK
   - 检查服务器项目的依赖是否完整
   - 查看输出窗口中的具体错误信息

4. **服务器启动失败**
   - 检查端口是否被其他程序占用
   - 确保有足够的系统权限
   - 查看输出窗口中的错误详情

### 调试提示
- 使用服务器输出窗口查看详细的错误信息
- 启用时间戳帮助追踪问题发生时间
- 使用过滤功能快速定位特定类型的消息
- 保存日志文件以便后续分析

## 开发扩展

如需扩展功能，可以：

1. 在 `ServerManagerTool` 中添加新的服务器管理方法
2. 在 `ToolBarMenu` 中添加新的工具栏按钮
3. 在 `ServerOutputWindow` 中添加新的日志处理功能
4. 在 `NetConfig` 中添加新的配置选项

所有组件都遵循VomitLib的编码规范和架构模式。
